---

## ✦ Desarrollo Local

### Requisitos
- Node.js 18+
- npm o pnpm

### Instalación y Ejecución

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build

# 4. Previsualizar compilación
npm run preview
```
